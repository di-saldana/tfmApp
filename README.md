# ConcertPal

ConcertPal es una aplicación móvil diseñada para conectar a los amantes de la música a través de eventos y conciertos. Utilizando las últimas tecnologías en desarrollo móvil, ConcertPal permite a los usuarios conectar sus datos musicales de Spotify, descubrir eventos cercanos basados en sus gustos, y hacer "matches" con otros usuarios con intereses similares. La aplicación también ofrece funciones de chat, notificaciones y un sistema de compatibilidad basado en similitud de gustos musicales.

## Características Principales

- Conexión con datos musicales de Spotify
- Descubrimiento de eventos musicales cercanos
- Sistema de "matches" basado en gustos y experiencias
- Personalización de perfil del usuario
- Funcionalidad de chat con matches
- Notificaciones de nuevos matches
- Visualización de posibles matches interesados en el mismo evento
- Desconexión de datos de Spotify

## Requisitos

- Node.js (incluye npm)
- Ionic CLI
- Capacitor CLI
- Android Studio (para desarrollo en Android)
- Xcode (para desarrollo en iOS)

## Pasos para Ejecutar el Proyecto

1. **Clonar el Repositorio**

   ```bash
   git clone https://github.com/di-saldana/tfmApp.git
   cd tfmApp
   ```

2. **Instalar las Dependencias**

   ```bash
   npm install
   ```

3. **Construye la Aplicación**

   ```bash
   ionic serve
   ```

   Para construir y ejecutar la aplicación en un dispositivo Android o iOS:

   ```bash
   ionic cap sync
   ionic cap open android   # Para Android
   ionic cap open ios       # Para iOS
   ```
